```

│                      │
│    🌿 水墨池塘       │

│   两座村庄剪影       │

│                      │
│   ── 水面倒影 ──     │
│                      │
│  ╔══════════════╗    │
│  ║  上岸        ║    │
│  ║  基于研究生   ║    │
│  ║  培养视角导读  ║    │
│  ║  杨柳坝与     ║    │
│  ║  刘家湾中间   ║    │
│  ║  隔着一张大塘  ║    │

│                      │

```

### 参数
- 尺寸：800×800 px（闲鱼首图标准）
- 色板：
  - 主色：水墨绿 #2d5016
  - 背景：米白 #f5f0e8 / 宣纸质感
  - 标题：深墨 #1a1a1a
  - 强调：朱红 #c04040（用于印章/回目编号）
- 字体：标题用「方正清刻本悦宋」或「思源宋体」加粗
- 意象元素：
  - 池塘水面（水墨渲染）
  - 两座村庄剪影（左为杨柳坝，右为刘家湾）
  - 远处一条小路通向水面（暗喻"上岸"之路）
  - 右上角一枚"点暇斋"朱红印章
