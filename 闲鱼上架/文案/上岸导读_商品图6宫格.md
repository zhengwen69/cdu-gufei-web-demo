# 上岸导读 —— 商品图 6 宫格布局方案

## 图1：封面（首图·引流）

| 内容 | 说明 |
|------|------|
| 来源 | 按《封面构图方案》生成 800×800 封面 |
| 核心信息 | 书名 + 作者 + 30万字·章回体长篇 |
| 颜色 | 水墨绿 + 宣纸白 |
| 注意 | 必须有书名和作者，否则闲鱼可能判定为无实物 |

---

## 图2：目录页（证明厚度）

| 内容 | 说明 |
|------|------|
| 来源 | 从原 PDF 截取目录页（如无，则从源文件生成前 50 回合目标签列表） |
| 展示 | 前 50 回目录的对句标题列表 |
| 标注 | 叠加文字 "完整目录" |
| 目的 | 让买家直观感受内容的体量和章回体标题的文采 |

---

## 图3：正文金句页 ①（展示文风）

| 内容 | 说明 |
|------|------|
| 来源 | 从原 PDF 截取代表性的正文页（如第 172 回"论证会上专家语 八秒沉默震人心"） |
| 标注 | 叠加文字 "章回体纪实·文白交融" |
| 目的 | 展示排版质量和文字风格 |

---

## 图4：正文金句页 ②（展示多样性）

| 内容 | 说明 |
|------|------|
| 来源 | 截取另一条故事线的正文页（如杨柳坝/刘家湾线的第 287 回"杨柳坝调研分类难"） |
| 标注 | 叠加文字 "五条故事线并行·多视角叙事" |
| 目的 | 展示内容的跨度和叙事多样性 |

---

## 图5：版权与合规（信任背书）

| 内容 | 说明 |
|------|------|
| 构成 | ① 版权登记声明文字（"全部作品版权登记·自有版权独立发行"）<br>② 作者简介摘要（3 行）<br>③ 闲鱼合规声明（"本商品为作者自有资料合法转让·非盗版电子书"） |
| 背景 | 深色底 + 金色文字 |
| 目的 | 消除"盗版电子书"疑虑，建立信任 |

---

## 图6：交付说明 + 关联导流

| 内容 | 说明 |
|------|------|
| 上方 | "拍下留言邮箱·24h内发送百度网盘" 的交付流程图（极简三步：拍下→留言→收货） |

---

## 图片制作建议

- 工具：Canva / 稿定设计 / PPT 截图
- 格式：JPG，800×800 px
- 用 PPT 做 6 张图是最简单的方式：每页 PPT 导出为 800×800 的 PNG→JPG
- 正文截图需从 PDF 中截取（确保文字清晰，不含出版社信息）
