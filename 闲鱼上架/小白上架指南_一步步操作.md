## 第1步：安装闲鱼 App（如果还没有）

1. 打开手机上的「应用商店」（苹果叫 App Store）
2. 搜索「闲鱼」
3. 点「安装」
4. 安装完点「打开」

---

## 第2步：登录（用淘宝账号）

1. 打开闲鱼 App，点「我的」标签（右下角小人图标）
2. 点「登录/注册」
3. 选「淘宝账号一键登录」
4. 同意授权
5. 登录成功后，点底部中间的「卖闲置」黄色按钮

---

## 第3步：上传 6 张宝贝图片

点「卖闲置」后会进入发布页面。

### 上传图片

1. 点「+」号添加图片
2. 从手机相册中按顺序选择 6 张图（图1 → 图2 → 图3 → 图4 → 图5 → 图6）
3. 点「完成」

> ⚠️ **顺序很重要**：第1张是封面，第2张是目录……一定要按 1→2→3→4→5→6 的顺序选。

---

## 第4步：填写标题

在「标题」输入框中，复制粘贴下面这行（一字不差）：

```
上岸：基于研究生培养视角导读杨柳坝与刘家湾 点暇斋 章回体纪实教育资料 PDF电子版
```

> 📌 标题限 30 字，上面刚好 28 字。

## 第6步：设置分类和价格

往下滑，依次设置：

| 选项 | 选什么 |
|------|--------|
| **分类** | 点进去 → 选「图书/音像」→ 选「其他图书」 |
| **价格** | 输入 `19.90` |
| **库存** | 输入 `999` |
| **发货方式** | 选「虚拟发货」或「无需物流」 |
| **成色** | 选「全新」 |

> ⚠️ 分类一定选「图书/音像」，不要选「虚拟商品」。

---

在「宝贝标签」（有些版本叫「关键词」）里添加这些：

```

```

## 第8步：添加关联商品（如果有的话）

如果你已经在闲鱼发布了其他商品（如 PPT、IP孵化报告 等），点「关联商品」勾选它们。

如果没有，跳过这步。

---

## 第9步：发布

检查一遍上面填的内容：

- [ ] 6张图顺序对吗？
- [ ] 标题粘贴正确吗？
- [ ] 描述粘贴完整吗？
- [ ] 分类选「图书/音像 → 其他图书」吗？
- [ ] 价格是 19.90 吗？
- [ ] 发货选「虚拟发货」吗？

确认无误后，点右上角的 **「发布」** 按钮。

🎉 **发布成功！** 现在可以在「我的 → 我发布的」里看到自己的宝贝了。

---

## 第10步：设置自动回复（买家咨询时自动发送）

1. 回到闲鱼首页，点「我的」（右下角）
2. 点右上角的「设置」图标（齿轮⚙️）
3. 找到「消息设置」或「自动回复」
4. 点「开启自动回复」
5. 在输入框中粘贴：

```
感谢关注！本资料为点暇斋章回体纪实小说PDF电子版（约200MB）。

拍下后请在聊天中留言您的邮箱或百度网盘账号，24小时内发送完整版PDF。同时赠送轻量预览版（前15回合集试读）。

如需了解作者其他作品（绩效新政解读/IP孵化报告/四种非标新出口PPT），请在聊天中发送"其他作品"。

——点暇斋 · 全部作品版权登记
```

6. 点「保存」


## 常见问题

### Q：有人问「是纸质书吗？」
**答**：您好，本书是PDF电子版，非纸质实体书。通过百度网盘发送，支持手机/电脑/平板阅读。拍下后24h内发送链接。

### Q：有人问「能便宜吗？」
**答**：您好，本资料为作者原创作品，定价已是知识分享价。如需试读，拍下后赠送前15回预览版。

### Q：有人问「能退货吗？」
**答**：您好，电子资料一经发送不支持退货哦。建议先看商品详情页中的预览图和试读内容，确认合适再拍。
