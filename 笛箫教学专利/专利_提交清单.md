## 流程节点预估

| 节点 | 时间 | 说明 |
|------|------|------|
| 提交申请 | T+0 | 电子提交或邮寄至CNIPA |
| 受理通知书 | T+2-4周 | 获得申请号 |
| 初步审查合格 | T+3-6个月 | 格式审查通过 |
| 申请公布 | T+18个月 | 在专利公报上公布（或请求提前公开：T+3-6个月） |
| 实质审查请求 | T+36个月内 | 逾期未请求视为撤回 |
| 第一次审查意见 | T+18-30个月 | 审查员发出审查意见通知书 |
| 答复审查意见 | T+4个月内 | 可延期 |
| 授权公告 | T+24-48个月 | 获得专利证书 |
| 年费缴纳 | 每年 | 从申请日起算第2年开始缴纳 |
