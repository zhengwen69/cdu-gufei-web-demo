# 境模块 —— 场景参数表

## 场景1：入门筑基

| 参数 | 设定值 | 说明 |
|------|--------|------|
| 噪音强度 | 0 dB（关闭） | 初学者无需环境干扰，保持安静专注 |
| 触觉反馈 | 关闭 | 入门阶段不引入触觉提示，避免分心 |
| 合奏延迟 | 不适用 | 独奏练习，无合奏声部 |
| 视觉提示 | 绿色背景光 | 营造放松、无评判的学习氛围 |
| 诊断评估 | 静默记录模式 | 后台采集但不即时展示雷达图，避免初学者的"分数焦虑" |
| 叙事激活 | 完整叙事情境卡 | 含背景故事文本、背景音频、表情标记全量呈现 |
| 评估触发条件 | 学习者手动请求 | 由学习者自主决定何时查看诊断结果 |
| 适用曲目 | 沧海一声笑 / 其他单音阶练习曲 | 音域不超过一个八度，节奏为全音符或二分音符 |

## 场景2：技法进阶

| 参数 | 设定值 | 说明 |
|------|--------|------|
| 噪音强度 | 20-30 dB | 轻度的环境噪音，训练在轻微干扰中保持专注 |
| 触觉反馈 | 实时提示模式 | 当音准偏差超过 ±10 音分时，手环以 5Hz 频率短振（50ms）提醒 |
| 合奏延迟 | 不适用 | 独奏进阶练习 |
| 视觉提示 | 黄色背景光 | 黄色暗示"目标清晰"——学习者明确知道需要改进的维度 |
| 诊断评估 | 实时雷达图模式 | 每遍演奏完成后即时展示五维雷达图 |
| 叙事激活 | 技术拆解卡 | 将曲目分解为音阶→乐句→全曲三段，每段有独立叙事标记 |
| 评估触发条件 | 每遍演奏完毕自动触发 | 提供即时反馈，支持"练习→诊断→修正→再练习"快速循环 |
| 适用曲目 | 姑苏行 / 梅花三弄 / 牧民新歌 | 涉及多种技巧组合，适合分维度诊断 |

---

## 场景3：合奏排练

| 参数 | 设定值 | 说明 |
|------|--------|------|
| 噪音强度 | 40-50 dB | 模拟排练室背景噪音（乐器摆放声、翻谱声、低声交谈） |
| 触觉反馈 | 节拍器振动模式 | 手环以设定 BPM 的 2 倍频率振动（如下拍强振 10Hz/200ms + 弱拍轻振 4Hz/100ms） |
| 合奏延迟 | 50ms → 0ms（可调梯度） | 从 50ms 起步，每通过一次合奏降低 10ms，直至 0ms 完美对齐 |
| 视觉提示 | 橙色背景光 + 投影节拍网格 | 投影屏幕实时显示：期望节拍位置（白点）、各演奏者实际拍点（彩色点） |
| 诊断评估 | 合奏对齐评分图 | 以"总对齐偏差（ms）"为纵轴、时间为横轴的折线图，三条线分别代表三个声部 |
| 叙事激活 | 多声部角色卡 | 每位学习者收到角色卡（如"你是主旋律——如领头马""你是低音——如大地脉动"） |
| 评估触发条件 | 合奏完毕自动触发 | 展示合奏对齐评分，按声部排名 |
| 适用曲目 | 茉莉花（合奏版）/ 牧民新歌（合奏版） | 有明确声部分配的合奏编曲 |

## 场景4：即兴创作

| 参数 | 设定值 | 说明 |
|------|--------|------|
| 噪音强度 | 50-70 dB（如选择"公演模式"） | 模拟真实演出环境：观众低声交谈、手机铃声、座椅挪动声等复合噪音 |
| 触觉反馈 | 情感提示模式 | 根据创作命题的情感方向，手环振动频率随情感强度变化（悲伤 <3Hz → 激昂 >12Hz） |
| 合奏延迟 | 不适用 | 即兴创作为独奏评估，或与固定伴奏轨对齐 |
| 视觉提示 | 渐变灯光模拟 | CSS 动画控制屏幕背景从暗蓝（准备）→暖橙（演奏中）→渐暗（收尾），模拟舞台灯光变化 |
| 诊断评估 | 创造性评分（三联评估） | 风格契合度 + 风格辨识度 + 即兴复杂度，输出综合评分和风格标签建议 |
| 叙事激活 | 开放命题卡 | 提供 3 个创作方向供选择（如"落日""重逢""告别"），每个方向附一句话情境提示 |
| 评估触发条件 | 演奏结束后手动触发 | 学习者有"再来一遍"的权利，迭代至满意后提交最优版 |
| 适用模式 | 示例1: 以《茉莉花》主题为素材，自由创作3分钟即兴华彩段落 | 示例2: 以五声音阶为素材，创作一个16小节的原创旋律 |

---

## 场景通用参数汇总

| 参数 | 入门筑基 | 技法进阶 | 合奏排练 | 即兴创作 |
|------|---------|---------|---------|---------|
| 噪音（dB） | 0 | 20-30 | 40-50 | 50-70 |
| 触觉模式 | 关闭 | 偏差提示 | 节拍器 | 情感提示 |
| 手环频率（Hz） | — | 5 | 10/4（强/弱拍） | 3-12（动态） |
| 评估模式 | 静默 | 实时雷达图 | 对齐折线图 | 三联评分 |
| 触发方式 | 手动 | 自动（每遍） | 自动（合奏毕） | 手动（迭代） |
| 场景色 | 绿 | 黄 | 橙 | 蓝→橙渐变 |
| 叙事载体 | 完整故事卡 | 技术拆解卡 | 角色卡 | 命题卡 |

## 境模块与其它模块的联动规则

```
叙模块激活 → 框模块进入待命 → 学习者开始练习
  ↓
框模块诊断 → 若偏差 < 阈值 → 提示"可以进入境模式"
  │                                     ↓
  │                          境模块加载对应场景参数
  │                                     ↓
  │                          学习者在场景中练习 → 框模块持续诊断
  │                                     ↓
  │                          若场景中偏差达标 → 提示"可进入创模式"
  │                                                         ↓
  └──────────────────────────── 创模块评估 ←── 学习者提交即兴创作
```
