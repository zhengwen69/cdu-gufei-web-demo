### 独立权利要求 1（草案）

```
1. 一种基于叙·框·境·创四维框架的笛箫民乐交互式教学系统，
   其特征在于，包括：

   叙事情境模块（叙），配置为：
     - 存储多首笛箫练习曲目及与每首曲目关联的叙事情境数据包，
       所述数据包包括情境文本描述、背景音频、演奏表情标记；

   框架诊断模块（框），配置为：
     - 通过音频采集单元实时获取演奏音频信号；
     - 利用音高检测算法提取音准偏差、节奏偏差、气息平稳度参数；
     - 将参数与预设的技术错配诊断矩阵比对，输出可视化诊断报告；

   场景淬炼模块（境），配置为：
     - 生成模拟演出环境的交互参数，包括背景噪音强度、
       合奏声部延迟量、视觉提示；
     - 通过可穿戴触觉反馈设备输出触觉提示信号；

   创造评估模块（创），配置为：
     - 接收即兴演奏音频，提取特征向量；
     - 与预设的框架模板库进行相似度计算，输出创造性评分及风格标签。
```

### 从属权利要求设计（2-12）

| 权利要求 | 限定内容 | 增补技术特征 |
|----------|---------|------------|
| 2 | 叙 | 叙事情境数据包关联 ≥3 个叙事标签（地域/情节/情感） |
| 3 | 框 | 音频采集为浏览器 Web Audio API 的 MediaStream 接口 |
| 4 | 框 | 音高检测采用自相关函数法（ACF），帧长 2048 样本 |
| 5 | 框 | 技术错配诊断矩阵包含音准/节奏/气息/指法/音色五维度 |
| 6 | 境 | 背景噪音强度可调范围 40-70dB |
| 7 | 境 | 触觉反馈设备为蓝牙手环，振动频率 2-15Hz |
| 8 | 创 | 相似度计算采用余弦相似度，阈值可调 0.3-0.95 |
| 9 | 创 | 框架模板库包含 ≥50 个风格模板 |
| 10 | 部署 | 系统部署于静态网页服务器，零配置分发 |
| 11 | AI | 包括云端 AI 助教模块，基于学习进度数据生成个性化练习建议 |
| 12 | 跨乐器 | 所述笛箫民乐教学系统同样适用于尺八、葫芦丝 |

### 方法独立权利要求（13）

```
13. 一种基于叙·框·境·创四维框架的笛箫民乐交互式教学方法，
    包括：
    S1（叙）：向学习者呈现与练习曲目关联的叙事情境数据包；
    S2（框）：实时采集演奏音频，提取技术偏差，输出诊断报告；
    S3（境）：在模拟演出环境中引导学习者重复练习至达标；
    S4（创）：接收即兴演奏，进行框架匹配度评估，输出创造性反馈。
```

### 存储介质与设备权利要求（14-15）

```
14. 一种计算机可读存储介质，其上存储有计算机程序，
    所述程序被处理器执行时实现权利要求 13 所述的方法。

15. 一种电子设备，包括处理器、存储器、麦克风模块和显示器，
    用于执行权利要求 13 所述的方法。
```

## 三、6 个实施例

| 实施例 | 场景描述 | 四维重点 | 硬件 | 说明 |
|--------|---------|----------|------|------|
| **1** | 固废课程门户（已有原型） | 全四维 | 任意浏览器 | 证明方法原型已在工程教育中验证，可迁移至音乐教育 |
| **2** | 成人零基础笛箫入门 | 叙 | 手机 + 普通竹笛 | 曲目《沧海一声笑》绑定武侠叙事，手机麦克风采音 |
| **3** | 中高级技法进阶 + 合奏排练 | 框 + 境 | 平板 + 蓝牙拾音器 + 手环 | 五维诊断→精准纠偏；合奏延迟模拟→队列对齐训练 |
| **4** | 社区公益演奏（线上线下混合模式） | 创 | 线下笛箫 + 线上评估系统 | 面授演奏后系统出具诊断报告；即兴段落匹配框架模板 |
| **5** | 机构集体课教学 | 境 + 创 | 平板 + 多副手环 | 境模块全开：虚拟观众噪音 + 触觉反馈 + 分组竞争评分 |
| **6** | 跨乐器迁移验证（尺八/葫芦丝） | 全四维 | 与实施例 1-3 同架构 | 证明四维框架对吹管乐器类的普适性 |

## 四、笛箫教学场景详情

| 教学场景 | 对应四维 | 叙事素材 | 技术诊断维度 | 产出形式 |
|----------|----------|---------|------------|---------|
| **入门筑基** | 叙为主 | 曲目背景故事卡片（民间传说/历史典故→触发情感记忆） | 口风稳定性 / 持笛姿势 | 情境体验日志 |
| **技法进阶** | 框为主 | 经典曲目技术拆解（音阶→乐句→全曲） | 音准 ±音分 / 节奏 ms 偏差 / 气息 dB 波动 | 可视化诊断雷达图 |
| **合奏排练** | 境为主 | 多声部角色卡（主旋律/伴奏/低音） | 合奏对齐偏差 / 声部平衡 | 合奏评分 + 角色扮演体验 |
| **即兴创作** | 创为主 | 开放命题框架（给定主题+情感方向→自由即兴） | 即兴与模板相似度 / 风格辨识度 | 创造性评分 + 风格标签 |

## 五、四维教学法 → 笛箫映射表

| 四维 | 工程教育原型 | 笛箫教学映射 | 技术实现 |
|------|------------|------------|---------|
| **叙** | 纪实小说选段 → 触发空间错配认知 | 曲目故事卡 → 触发演奏情感共鸣 | JSON 数据包 + `<audio>` 背景音轨 |
| **框** | 六子错配-修复诊断矩阵 | 技术五维：音准/节奏/气息/指法/音色 | `AnalyserNode.getByteFrequencyData()` + ACF 音高检测 |
| **境** | 环评答辩/选址听证/模拟法庭 | 三级演出场景：独奏回课/合奏对齐/公演压力 | `OscillatorNode` 噪音 + CSS 灯光动画 |
| **创** | 三轨制（论文/设计/教改） | 三轨制：改编/即兴/教学反思 | 特征提取 → 余弦相似度匹配模板库 |

## 七、新颖性论证

| 现有技术 | 局限 | 本发明创新 |
|---------|------|----------|
| 智能乐器评分（雅马哈 AI） | 仅评分；无叙事情境；无演出压力模拟 | 四维递进：情感触发→框架诊断→场景淬炼→创造评估 全闭环 |
| 音乐教学 App（Simply Piano） | 仅键盘乐器；无吹管乐器气息/口风检测 | 多模态：音频 + 气息波动 + 指法过渡时间 |
| VR 演出模拟 | 仅场景模拟；无诊断框架联动 | 场景淬炼 × 框架诊断联动：压力环境下的量化评估 |
| 传统师徒教学 | 无技术系统 | 首次将"叙·框·境·创"四维框架系统化、可装置化 |
