▸ 模块① 固体废物来源（§1.2）

  • 工业固废（ISW）：冶金（高炉渣/钢渣）· 电力（粉煤灰/脱硫石膏）· 有色（赤泥/铜渣）· 化工（电石渣/磷石膏）· 采矿（煤矸石/尾矿）；产生量最大、成分最复杂、行业间差异大。
  • 农业固废：秸秆（年约 7 亿吨、利用率约 33%）· 畜禽粪便 · 农膜；季节性强、来源分散、有机质高。
  • 城市生活垃圾（MSW）：厨余（40%–60%）/纸/塑料/织物/玻璃/金属/灰渣；组分受地区·季节·习惯影响。
  • 建筑垃圾：拆除/装修/渣土；城镇化集中产生、量大、可资源化（再生骨料）。

三维度分类（易混）

来源（从哪来）性质（危不危险）方式（怎么处理）
工业 / 农业 / 生活 / 建筑一般固废 / 危险废物（HW）可回收 / 可堆肥 / 可燃 / 惰性

口诀：来源问"从哪来"，性质问"危不危险"，方式问"怎么处理"，三把尺子各量各的。（例：废电池 → 生活 / 危废 / 有害垃圾）

集合图：危险废物是"具有毒/腐/易燃/反应/感染等危害特性"的子集，套在各大类里，非并列的第四类。

因果链：来源决定组分 → 组分决定特性 → 特性决定处理方式（工业→资源化 / 农业→生物 / 生活→焚烧填埋 / 建筑→再生骨料）。

▸ 模块② 八大危害途径（§1.3）

气 · 水 · 土 · 地 · 卫生 · 灾害 · 景观 · 温室
  • ①污染大气：粉尘 + 恶臭（H₂S/NH₃/硫醇）+ VOCs/二噁英
  • ②污染水体：渗滤液（Leachate，COD 数万 mg/L）入地表水/地下水（最隐蔽）
  • ③污染土壤：重金属/POPs 入土 → 食物链放大
  • ④占用土地：填满易恢复难、垃圾围城
  • ⑤影响环境卫生：蚊蝇传病、医疗废物
  • ⑥引发地质灾害：尾矿库溃坝/堆体滑坡/填埋气爆炸
  • ⑦视觉污染：白色污染、破坏市容
  • ⑧温室气体：填埋 CH₄，温室效应为 CO₂ 的 25 倍

危害链（介质传递）：一个垃圾堆 → 渗滤液 → 地下水/土壤 → 作物/人体 —— 八条是连锁反应，非孤立；核心概念是二次污染。

S003《龙栖湾》：填埋场来了 → 杏树不结果 / 井水怪味 / 地不值钱 → "敢让孩子喝吗"。相关概念：邻避效应（NIMBY）。

▸ 模块③ 物化生特性（§1.4–1.6）

四大核心参数

  • 含水率：湿基＝水/湿垃圾 ×100%，生活垃圾 40%–60% → 决定能否烧、运输、渗滤液。
  • 容重：原位 0.3–0.6 t/m³、压实 0.8–1.0 t/m³ → 决定运输量、填埋库容。
  • 热值：LHV 3500–6500 kJ/kg；HHV 含潜热、LHV 扣潜热（汽化潜热 ≈2260 kJ/kg）。换算：LHV ≈ HHV − 2260×(9H+W)/100。
  • B/C 比：>0.45 易生化 / 0.3–0.45 可生化 / <0.3 难生化 → 决定生物 vs 非生物处理。

参数 → 决策链

参数决定对接章节
热值焚烧自持（LHV≥3350）第五章
容重运输/库容第三、八章
B/C生物处理第六章
浸出毒性危废判定第八章

提醒：AI 会编参数值，必须回教材/标准核对。

▸ 模块④ 3C 管理理念

Clean（避免产生）· Cycle（综合利用）· Control（妥善处置）

主线：源头 → 过程 → 末端

三化 / 3R / 3C 辨析（必考）

概念导向内容
三化目标导向减量化 / 资源化 / 无害化
3R操作导向Reduce / Reuse / Recycle（国际优先序）
3C管理导向Clean / Cycle / Control（全生命周期）

优先序金字塔：源头减量（Clean/减量化）＞ 资源化循环（Cycle/Recycle）＞ 末端无害化（Control/无害化）。能减就不循环，能循环就不填埋。

扩展：EPR 生产者责任延伸 · LCA 全生命周期评价 · 无废城市 Zero-Waste City。

▸ 随堂例题（自测）

例1：100kg 垃圾湿基含水率 60%，水与干物质各多少？
答：水 60kg、干物质 40kg。

例2：HHV=6500 kJ/kg、氢含量 5%、含水率 30%，求 LHV？
答：LHV ≈ 6500 − 2260×(9×5+30)/100 ≈ 4805 kJ/kg。

例3：BOD₅=18000 mg/L、COD=40000 mg/L，求 B/C 与处理方式？
答：B/C=0.45，可生物处理（堆肥/厌氧）。
